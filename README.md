# 她 · 本地 AI 伴侣

> 一个只跑在你自己电脑上的 AI 伴侣。手机聊天，电脑处理，蓝牙直连玩具。
> 没有云账号，没有订阅，聊天记录不出你的机器（除了发给大模型的那几句话）。

## 这是什么

一个自托管的 AI 伴侣，把三件事连在一起：

1. **聊天** —— 手机浏览器打开就是聊天界面，带历史、时间戳，能装到主屏
2. **记忆** —— 她的名字、怎么称呼你、你的边界、你们定下的约定，都存在本地
3. **身体** —— 通过本地蓝牙控制啵啵贝（吮吸 / 震动 / 电流），AI 自己决定什么时候、多强

配套一个电脑端控制台：看状态、翻记录（含每一次工具调用）、改人设和她叫什么。

**隐私边界说清楚**：对话内容会发给 DeepSeek 做推理；聊天记录、人设、约定、玩具控制全部只在你电脑上。没有第三方服务器。

---

## 特性

- **对话与记忆**：人设可在线编辑、立即生效；长期事实与「关系协议」由 AI 自己写入并长期携带
- **初次见面流程**：第一次聊天不是直接进角色，而是先了解边界、约定安全词，再一起写下协议
- **工具调用**：震动 / 吮吸 / 电流 / 全停 / 定时器 / 记住事实 / 保存协议
- **她可以主动说话**：`set_timer` 让她 N 分钟后自己开口，锁屏也能收到通知
- **安全词**：输入完全匹配的短语，立刻全停，**不经过大模型**
- **断线兜底**：手机关掉或断网超过 N 秒，自动停止所有马达（锁屏不算）
- **离线消息队列**：锁屏期间她说的话不会丢，亮屏重连后补发
- **推送**：Web Push，锁屏能弹通知（需要 HTTPS）
- **单端口**：一个 8000 端口同时提供网页、WebSocket、控制 API

## 架构

```
┌─────────────┐   WebSocket    ┌──────────────────────────────┐
│  手机浏览器  │ ─────────────▶ │  FastAPI (8000)              │
│  或安卓 App │ ◀───────────── │   ├─ 静态页面 + /ws          │
└─────────────┘   推送(HTTPS)  │   ├─ LLM 工具循环 (DeepSeek) │
                               │   ├─ 定时器 / 记忆 / 资料     │
┌─────────────┐                │   └─ Web Push (VAPID)        │
│  电脑控制台  │ ─────────────▶ └──────────┬───────────────────┘
│  /admin.html│                            │ HTTP
└─────────────┘                            ▼
                               ┌──────────────────────────────┐
                               │ 玩具服务 (8765)              │
                               │  bleak → BLE → 啵啵贝        │
                               └──────────────────────────────┘
```

大模型永远不直接碰蓝牙：它只能调用工具，落地到本地 HTTP，再由本地服务写 BLE。**强度在本地强制夹在 0–100。**

## 快速开始

### 需要

- Windows 10/11（macOS / Linux 也能跑，脚本需自行调整）
- Python 3.9+
- 支持 BLE 的蓝牙适配器（见下方「蓝牙适配器」）
- 一个 DeepSeek API Key

### 三步

```bash
git clone <this-repo> ai_partner
cd ai_partner
cp .env.example .env        # 填 DEEPSEEK_API_KEY
```

双击 `启动.bat`。会拉起两个服务并打开控制台。

手机连同一个 Wi-Fi，浏览器打开 `http://<电脑IP>:8000`。

### 首次使用

打开手机页面，她会先和你聊几句：怎么称呼、哪些可以、哪些绝对不行、安全词想用什么。聊完她会把内容写成一份约定存下来。之后每次对话她都会记得。

## 配置（`.env`）

| 键 | 默认 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | 空 | 不填则进入测试模式，只回固定话术 |
| `DEEPSEEK_MODEL` | `deepseek-chat` | 模型名 |
| `SAFE_WORD` | `停一下` | 输入完全等于它 → 立刻全停，绕过模型 |
| `AUTO_STOP_AFTER_DISCONNECT` | `90` | 手机端全断后多少秒自动停；`0` 关闭 |
| `PORT` | `8000` | 网页端口 |
| `TOY_BASE_URL` | `http://127.0.0.1:8765` | 玩具服务地址 |
| `ACCESS_PASSWORD` | 空 | 设了之后要登录。**暴露到公网前务必设置** |

## 三个界面

| 地址 | 给谁 | 内容 |
|---|---|---|
| `/` | 手机 | 聊天：历史、时间戳、日分隔、停止按钮 |

## 安卓 App（可选）

如果你的手机浏览器不给「添加到主屏幕」，可以用 GitHub Actions 直接编一个 APK，**本地不需要装 Android SDK**。

1. 把仓库推到 GitHub
2. 打开 repo 的 **Actions** → 选 `build apk` → **Run workflow**
3. 等约 3 分钟，在页面底部 **Artifacts** 下载 `ai-companion-apk`
4. 传到手机安装（需要允许「未知来源」）

首次打开会让你填电脑地址，之后全屏加载，跟原生 App 一样。源码在 `android/`，只有一个 WebView 外壳，没有第三方依赖。

## 蓝牙适配器（重要）

不是所有「蓝牙 5.0」U 盘都能扫到 BLE 设备。我踩过的坑：**TP-Link TL-UB250（Realtek RTL8761BUV）** 在 Windows 通用驱动下经典蓝牙正常，但 BLE 接收是空的——不报错，只是永远扫不到任何设备。装上 Realtek 专用驱动后立刻正常（设备名会变成 `TP-Link Bluetooth 5.0 USB Adapter`）。

判断方法：

```bash
.venv/Scripts/python.exe scripts/watch_ble.py 30
```

一个设备都扫不到（连邻居的家电都没有）→ 驱动或适配器问题。

买之前认准「支持 BLE / 低功耗 / 可连手环」；只写「音频适配器」的多半只有经典蓝牙。

## 玩具协议

BLE 协议来自 [51enuxu/sosexy-ble-control](https://github.com/51enuxu/sosexy-ble-control)（MIT），针对 **Funf 啵啵贝 / SOSEXY** 这一款，设备名必须是 `SOSEXY`。换别的牌子需要自己改 `vendor/` 里的 UUID 和帧格式。

## 安全说明

- 玩具强度在本地夹 0–100，模型传什么都越不过去
- 安全词直接落到停止逻辑，不经过模型，也不经过网络往返
- 电流模式请在**皮肤干燥完整**的前提下使用，避开胸口、颈部、头部
- 不要把服务直接暴露到公网还留空密码。要远程用，优先 [Tailscale](TAILSCALE.md) 这类私有网络

---

## 已知限制

- Tailscale 的 HTTPS 证书走 Let's Encrypt，在部分网络下会被阻断 → 推送不可用。替代方案：Cloudflare Tunnel + 自己的域名
- 部分机型浏览器不支持 `PushManager` → 没有推送，只能亮屏看
- 玩具同一时间只允许一个 BLE 连接，电脑连上后手机官方 App 就连不上
